# 📝 Task Manager App

A simple and interactive Task Manager built using **HTML, CSS, and JavaScript**.
This app allows users to manage daily tasks with features like categories, priority levels, and status tracking.

---

## 🚀 Features

* ✅ Add new tasks
* 🗂️ Assign category (Work, Personal, etc.)
* ⚡ Set priority (Low, Medium, High)
* 🔄 Update task status (In-progress / Complete)
* ✔ Mark tasks as completed (with strikethrough effect)
* 🗑 Delete tasks
* 💾 Data stored using **Local Storage**

## ⚙️ How It Works

1. User enters a task
2. Task is stored in localStorage
3. Task is dynamically rendered in UI
4. User can update status, category, and priority
5. Changes are saved automatically
